# Desafios

Projeto destinado a armazenar minhas soluções de desafios de programação, algoritmos e exercícios de lógica, com foco na prática de C# e testes unitários utilizando xUnit.

## Estrutura

- `src/Desafios/`: biblioteca de classes (Class Library) contendo as soluções dos exercícios.
- `tests/Desafios.Tests/`: projeto de testes unitários utilizando xUnit para validar as soluções.
